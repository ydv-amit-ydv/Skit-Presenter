Skit Cue Player

Each scene has one background and an ordered list of audio cues. In the player, Space fires the next cue. Use the ✂ button on a cue to trim its start and end (drag the edges on the waveform). Tick auto on a cue to have it start automatically when the previous one ends. The saved .json embeds all images, audio and trim points, so one file carries the whole show. To edit a saved show, select Open (or drop the .json onto this page), make changes, then Save.
